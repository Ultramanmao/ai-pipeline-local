## 1. The Goal / Problem

[v26.0](https://github.com/Ultramanmao/ai-pipeline-local/releases/tag/v26.0) proved Motion Context chaining works at 40 seconds (8 clips). But 40 seconds is still a short clip — real music videos, dance performances, and narrative films need 90-120 seconds minimum.

The challenge: scaling from 8 clips to 24 clips introduces problems that don't show up at smaller scales:

- **Facial degradation** accumulates over long chains — faces start drifting or deforming after 10+ clips
- **Action variety** gets harder — you need distinct choreography across 24 segments without repeating
- **Production time** explodes — at ~9 minutes per clip, 24 clips = 3.5 hours of GPU time
- **Quality control** becomes essential — one bad clip in the middle breaks the entire chain

We built a complete pipeline: storyboard → chained generation → quality screening → selective regeneration → post-production with BGM, titles, and credits.

## 3. Step by Step

### Step 1 — Reference Image Preparation

The source image is 1024×1024 square. Stretching to 832×480 crushes the figure horizontally. Solution: blur-fill the sides to reach landscape ratio without distortion.

```python
from PIL import Image, ImageFilter

img = Image.open('dancer_square.png')  # 1024x1024
# Create blurred background at target ratio
bg = img.resize((832, 480), Image.LANCZOS)
bg = bg.filter(ImageFilter.GaussianBlur(radius=30))
# Paste original centered
offset_x = (832 - 560) // 2  # maintain aspect ratio
bg.paste(img.resize((560, 480), Image.LANCZOS), (offset_x, 0))
bg.save('dancer_landscape.png')
```

### Step 2 — Two-Act Storyboard

24 segments split into two acts:

**Act 1 (S01-S10, 50s)** — Standing choreography: arabesque → spin → sleeve play → poses
**Act 2 (S11-S24, 70s)** — Low choreography: kneeling → body waves → silhouette → fade out

Each act has its own production script. Act 2 chains from Act 1's final latent (`clip_00010.safetensors`).

### Step 3 — Chained Generation

Each clip runs through ComfyUI's H3 FL2VA pipeline. The key: Motion Context reads the previous clip's latent, maintaining color, lighting, and character appearance across the chain.

```python
# Simplified — actual script handles 24 segments
for i in range(1, 25):
    workflow['inputs']['context_length'] = 22
    workflow['inputs']['motion_context'] = f'clip_{i-1:05d}.safetensors'
    workflow['inputs']['prompt'] = ACT2_PROMPTS[i]  # per-segment choreography
    submit_to_comfyui(workflow)
```

**Production time:** Act 1 = 85 min (10 clips × ~8.5 min), Act 2 = 128 min (14 clips × ~9.1 min). Total: ~3.5 hours.

### Step 4 — Quality Screening

After generation, we screened all 24 clips frame-by-frame for hand/finger deformities — the most common H3 failure mode in dance videos.

**Results:** 10 of 24 clips had issues (42% failure rate):

| Problem Clips | Issue |
|--------------|-------|
| S09, S11, S12 | Fingers merging/clipping |
| S15, S16, S17 | Hand distortion during sleeve movements |
| S18, S22, S23, S24 | Finger deformation in close-up gestures |

Decision: regenerate S12-S24 (13 clips) with new seeds, screening each one before proceeding to the next.

### Step 5 — Selective Regeneration

The critical lesson: **you can only regenerate from the problem segment forward**. Replacing a middle segment with a different seed breaks the latent chain — the new segment's ending latent doesn't match the next segment's starting latent, causing a visible jump.

```
S01-S11: keep original (no issues)
S12: regenerate with new seed → screen → approve
S13: chains from new S12 → screen → approve
...
S24: chains from S23 → screen → approve
```

Each regeneration takes ~9 minutes. 13 segments = ~2 hours additional GPU time.

### Step 6 — Post-Production

```bash
# Concatenate acts
ffmpeg -f concat -safe 0 -i act1_list.txt -c copy act1.mp4
ffmpeg -f concat -safe 0 -i act2_list.txt -c copy act2.mp4

# Add BGM with offset (7s title card → music starts)
ffmpeg -i full_raw.mp4 -i bgm_with_offset.wav \
  -filter_complex "[1:a]volume=0.8[bgm]" \
  -map 0:v -map "[bgm]" -shortest full_with_bgm.mp4

# Add opening (cover → fade to black → fade in) and ending (credits scroll)
ffmpeg -i opening.mp4 -i full_with_bgm.mp4 -i ending.mp4 \
  -filter_complex "[0:v][1:v][2:v]concat=n=3:v=1:a=0[outv]" \
  -map "[outv]" -map 1:a tang_dancer_final.mp4
```

## 4. The Biggest Bug: Fingers in Dance Videos

**The problem:** Dance videos are the worst case for H3 hand rendering. Sleeve movements + gesture close-ups + rapid hand position changes = high finger deformity rate.

**What we tried:**

| Approach | Result |
|----------|--------|
| Lock face + lock camera in prompt | ❌ Changed body orientation — choreography broke |
| Split long segments (reduce rotation per clip) | ❌ Didn't fix underlying hand issue |
| Seed lottery (regenerate with different seed) | ✅ Works, but luck-based |
| Prompt: "stable hands, no finger deformation" | ⚠️ Helps slightly, not reliable |

**What actually worked:** Seed lottery + frame-by-frame screening. Each regenerated clip uses a different random seed. We check every frame (not just the compressed video) before approving. If hands look wrong, regenerate again with another seed.

**The lesson:** Hand deformity in dance videos is a model-level limitation, not a prompt engineering problem. The only reliable mitigation is generate → screen → regenerate if needed. Budget 2x the expected GPU time for dance content.

## 6. What We Learned

1. **Motion Context sweet spot: context_length=22.** Below 18, transitions are jarring. Above 25, everything looks like slow motion. 22 is the balance point for dance content.

2. **Turbo LoRA breaks chaining.** The 8-step turbo sampler produces visible seams between clips. Always use 20-step beta for chained generation.

3. **Square → landscape: blur-fill, never stretch or crop.** Stretching crushes the figure. Cropping loses limbs. Blur-fill preserves the subject at correct aspect ratio.

4. **Hand screening is mandatory for dance videos.** 42% failure rate on first generation. Budget time and GPU cycles for regeneration.

5. **You can only regenerate forward.** Replacing a middle clip breaks the latent chain. Always regenerate from the problem segment to the end.

6. **Two-act structure solves action variety.** Splitting into standing (Act 1) and low choreography (Act 2) gives natural visual variety without repeating movement patterns.

7. **Frame-by-frame beats video review.** Compression artifacts in rendered video can mask or exaggerate hand issues. Check the raw PNG frames.
