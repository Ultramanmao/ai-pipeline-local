## 3. The Five Dimensions

We tested DyPE+SEGA across five dimensions:

### 3.1 Resolution
| Resolution | Time | Output Size |
|------------|------|-------------|
| 512×512 | 7s | 0.8MB |
| 768×768 | 10s | 1.2MB |
| 1024×1024 | 16s | 1.8MB |
| **1312×1312** | **22s** | **2.24MB** |
| 1536×1024 | 28s | 2.1MB |
| 1024×1536 | 28s | 2.1MB |

**Key finding**: 1312×1312 is the native resolution sweet spot. Beyond that, we're in extrapolation territory.

### 3.2 Sampling Steps
| Steps | Time | Quality |
|-------|------|---------|
| 3 | 18s | Slightly soft |
| **4** | **22s** | **★ Sweet spot** |
| 6 | 30s | Marginal improvement |
| 8 | 38s | Diminishing returns |
| 12 | 54s | Overkill |
| 20 | 90s | Only for final renders |

**Key finding**: 4 steps is the sweet spot. Going from 4→8 steps adds 16 seconds for barely noticeable improvement.

### 3.3 Prompt Types
Tested five categories: Chinese text, landscape, portrait, abstract, food.

All five rendered correctly at 1312×1312. Chinese text rendering was the surprise winner — crisp and readable.

### 3.4 Random Seeds
Six seeds tested: 42, 1234, 2026, 5678, 8888, 9999.

All produced consistent quality. Seed affects composition but not quality. Pick any seed, get consistent results.

### 3.5 Creativity Modes
| Mode | Time | Description |
|------|------|-------------|
| off | 1s | Baseline |
| scrambled | 8s | Random noise injection |
| refined 1-step | 15s | Single refinement pass |
| refined 2-step | 24s | Two passes |

**Key finding**: Creativity mode adds 30+ seconds. Only worth it for final artistic renders, not for benchmarking.

## 5. The Biggest Bug: FFmpeg's Path Colon

Again. This is the third time this bug has bitten us.

FFmpeg's `filter_complex` uses `:` as a parameter delimiter. Windows paths like `E:/workout/...` have a colon at position 2.

FFmpeg sees `E:`, treats it as a filter parameter, and the entire chain explodes.

**Fix**: Convert all paths to relative paths before passing to FFmpeg. Working directory pinned to avoid colons.

```python
def _rp(p):
    """Convert to relative path to avoid E:/ colon breaking FFmpeg filters."""
    if os.path.isabs(p):
        return os.path.relpath(p, FFMPEG_CWD).replace("\\", "/")
    return p
```

Every path argument goes through `_rp()` first.

## 7. What We Learned

1. **DyPE works**. It breaks the 1024² ceiling. 1312×1312 is native, 2048×2048 is possible (with quality trade-offs).

2. **SEGA helps at high resolutions**. At 1312² and above, SEGA's spectral energy guidance prevents the washed-out look that high-res diffusion models sometimes produce.

3. **4 steps is the sweet spot**. For benchmarking and quick iteration, 4 steps gives you 90% of the quality at 50% of the time.

4. **Video beats screenshots**. A 70-second video with a digital human explaining results gets 10x more engagement than a static chart.

5. **The pipeline is reusable**. Swap out the benchmark data, regenerate slides, re-record voice, and you've got a new video in 30 minutes.
