## 1. The Goal / Problem

Text-to-Speech is the voice of every digital human, narration, and AI assistant. But on an 8 GB RTX 5060, you can't run all three engines at once. You need to pick one — and the wrong choice means either flat, emotionless audio or clipped, distorted output.

The question: **Which engine gives the best emotion control on consumer hardware?**

We tested MegaTTS3, IndexTTS 2.5, and CosyVoice2 head-to-head with identical text, reference audio, and six core emotions. No guessing — just data.

## 4. The Biggest Bug / Pitfall

**MegaTTS3's "surprised" emotion goes backwards.**

We set `emotion=surprised, alpha=0.8` expecting the voice to get louder, brighter, more energetic. Instead: RMS dropped to 0.90× baseline. The engine *reduced* volume when it should have increased it.

**What we tried**:
| Approach | Result |
|----------|--------|
| alpha=0.5 → 1.0 | No direction change |
| Different reference audio | Same issue |
| Vector interpolation | Still inverted |

**What fixed it**: Nothing. It's a model bug. Use IndexTTS 2.5 for surprised expressions — it's the only engine that gets the direction right.

**Second pitfall**: CosyVoice2's "strong" instruct labels do almost nothing. We tried "用极度愤怒的语气说" (speak in extremely angry tone) vs "用愤怒的语气说" (speak in angry tone). RMS difference: <10%. The engine is "duration-type" not "volume-type" — instruct controls *how long* the sentence takes, not *how loud* it gets.

## 6. What We Learned

1. **MegaTTS3 is a nuclear option** — 2.42× angry amplitude is unmatched, but 53 clipping points make it unusable without a limiter. If you need extreme emotion, add `ffmpeg -af "alimiter=limit=0.9"` post-processing.

2. **IndexTTS 2.5 is the production workhorse** — 1.84× angry with only 11 clips, plus 5–17 s speed. For digital humans and narration, this is the default.

3. **CosyVoice2 is the iteration engine** — 4 s/sentence means you can test 10 variations in the time MegaTTS3 generates one. Use it for prototyping, then switch to IndexTTS for final output.

4. **CosyVoice2's calm control is unique** — 0.57× RMS is the only engine that actually makes the voice quieter. For meditation, ASMR, or soft narration, nothing else comes close.

5. **Don't trust "strong" instruct labels** — CosyVoice2's natural language control affects duration, not volume. Write "用极度平静的语气慢慢说" (speak very calmly and slowly) instead of "用极度平静的语气说" (speak very calmly).

6. **The surprised emotion is broken in MegaTTS3** — It inverts the volume direction. Use IndexTTS 2.5 for surprised expressions.

## 7. What's Next

1. **Limiter integration** — Add automatic `ffmpeg alimiter` post-processing to the MegaTTS3 pipeline for angry/emotional outputs.

2. **Emotion vector interpolation** — Test IndexTTS 2.5 with blended vectors (e.g., 50% angry + 50% sad) for nuanced expressions.

3. **Production pipeline** — Build a smart router: CosyVoice2 for iteration → IndexTTS 2.5 for production → MegaTTS3 + limiter for extreme cases.

4. **Voice cloning stress test** — Test all three engines with noisy reference audio (street recording, phone call) to see which degrades gracefully.

## Summary

**IndexTTS 2.5 wins the emotion showdown** — 1.84× angry amplitude, 11 clipping points, 5–17 s speed. MegaTTS3 is stronger but needs a limiter; CosyVoice2 is faster but too flat. Pick based on your use case: iteration → CosyVoice2, production → IndexTTS 2.5, extreme emotion → MegaTTS3 + limiter.
