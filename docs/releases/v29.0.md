## 1. The Goal / Problem

Everyone's generating AI videos. But generating a video isn't the same as telling a story.

I had H3 R2V for video generation, CosyVoice2 for narration, and an 8 GB RTX 5060. The question: **Can I build a complete short film — from script to final render — on consumer hardware?**

The answer is yes, but it took 6 versions, a complete direction rewrite, and learning that FFmpeg's `amix` will silently destroy your audio.


## 4. The Biggest Bug / Pitfall

**FFmpeg `amix normalize=0` divides by N.**

We had 6 audio inputs (original + 5 narrations). With `amix=inputs=6`, each input was divided by 6 (-15.6 dB). The narration, which should dominate, was buried under the BGM.

**What we tried**:
| Approach | Result |
|----------|--------|
| `amix=inputs=6:normalize=0` | Still divides by N |
| `amix=inputs=6:normalize=1` | Normalizes to 0 dBFS, kills dynamics |
| `volume=18dB` before amix | Helps but still wrong |
| **Python numpy direct叠加** | ✅ Perfect control |

**What fixed it**: Stop using FFmpeg for mixing. Use Python numpy to directly add waveforms with precise volume control:
- Original audio: ×0.1 (-20 dB)
- Narration: ×6.3 (+18 dB) 
- BGM: ×0.1 (-20 dB)

**Second pitfall**: CosyVoice2's comma handling. "AI，至关重要。" produces a long silence after the comma, and the second part gets truncated. Short sentences should not have punctuation.

**Third pitfall**: `afftdn` noise reduction eats quiet ending syllables. Don't use it on short sentences with soft endings.

## 6. What We Learned

1. **Storyboard first, narration second** — v5 failed because we wrote narration before knowing the visual flow. Write storyboard → generate shots → write narration to match.

2. **Don't reveal AI too early** — v6's "前20秒不提AI" (don't mention AI in the first 20 seconds) lets viewers empathize with the problem before seeing the solution.

3. **R2V for character consistency** — Using the same reference image across all shots with Ref2VA ensures the character looks the same. I2V would drift.

4. **S4b: show, don't tell** — Adding a screen-closeup shot (S4b) shows AI in action without needing a face. Over-the-shoulder + blurred shoulders = no consistency issues.

5. **Python numpy > FFmpeg amix** — For multi-track mixing with precise volume control, FFmpeg's amix is unreliable. Python numpy gives you exact waveform control.

6. **CosyVoice2 comma bug** — Short sentences with commas produce truncation. Remove punctuation from short TTS inputs.

7. **8 shots × 8 minutes = 40 minutes** — On 8 GB with H3 R2V 8-step turbo, each shot takes 4-11 minutes. Budget 1 hour for a 46-second film.

---

## 7. What's Next

1. **Longer films** — Current limit is ~8 shots (46 seconds). For 2-3 minute films, need shot chaining (Motion Context or Director continuity).

2. **Emotion-driven BGM** — Current BGM is static volume. Next: match BGM intensity to narration emotion using CosyVoice2's RMS data.

3. **Multi-character** — Single character is easy. Two characters require separate generation + compositing. Three+ is still out of reach on 8 GB.

4. **English narration** — CosyVoice2 works for Chinese. For English, need IndexTTS 2.5 or ElevenLabs.
